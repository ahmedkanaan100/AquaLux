# AquaLux

AquaLux is a web platform for a luxury water-rental business offering **Jet Ski and yacht rentals**. The project focuses on presenting rental services through a clean, user-friendly website and making it easy for customers to explore available experiences and rental options.

## My Contribution

I contributed to the development of the AquaLux website, including:

- Front-end development and UI improvements
- Feature implementation
- Debugging and fixing website issues
- Improving page functionality and user experience
- Testing and refining existing components

## Technologies

- HTML
- CSS
- JavaScript
- Web Development
- Git & GitHub

## Project Purpose

The goal of AquaLux is to provide customers with a modern online experience for discovering and exploring premium Jet Ski and yacht rental services.
